# 📚 Sistema de Biblioteca - SQL

  📌 Descrição
Banco de dados relacional para gerenciamento de uma biblioteca, com controle de alunos, autores, livros e empréstimos.

  🛠️ Tecnologias
- SQL
- MySQL

  🧱 Estrutura
- Pessoa
- Aluno
- Autor
- Curso
- Livro
- Empréstimo

  📊 Consultas
- Listagem de empréstimos
- Empréstimos em aberto
- Quantidade de empréstimos por aluno

  🎯 Objetivo
Praticar modelagem de dados, criação de tabelas e consultas SQL com JOIN.
